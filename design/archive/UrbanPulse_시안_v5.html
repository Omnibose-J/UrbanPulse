들어오는 길

  • 주소로 들어오면 ① 홈
  • 공유 링크로 들어오면 ⑤ 하루 상세 (장소, 날짜, 조건이 링크에 담겨 있음)
  • ⑦ 지도에서 핀을 누르고 카드 버튼을 누르면 ⑤ 하루 상세

기억하는 것

  • 조건(목적, 사람 많고 적음)은 처음엔 "구경·산책 · 적당히"
  • 한 번 바꾼 조건은 다른 장소에서도 그대로 써요 (이 브라우저에만 저장)
  • 별표한 장소는 홈 "관심 장소"에 나와요

돌아가는 길

  • ⑤ → ③ → ① 순서로 한 단계씩 (왼쪽 위 버튼)
  • 조건 창은 바깥을 누르거나 닫기 버튼으로 닫으면 바꾸지 않아요
  • 역세권(추정)도 같은 흐름이고, 목적 선택만 없어요
⓪ 직접 눌러 보기홈부터 끝까지 이어져 있어요.
① 홈검색창을 누르면 ②, 장소를 누르면 ③
→
② 검색이름이나 역으로 찾기. 결과를 누르면 ③
→
③ 이번 주답 카드나 날짜를 누르면 ⑤, 조건 줄을 누르면 ④
④ 조건 바꾸기맛집을 고르면 준비 중인 "한적하게"는 막히고 이유가 나와요. 적용하면 ③이 바로 바뀌어요
→
⑤ 하루 상세시간 칸을 누르면 아래에 이유가 나와요
→
⑥ 추천할 시간이 없는 날더 나은 날 → ⑤ (다른 날짜), 비슷한 곳 → ⑤ (다른 장소, 같은 날)
⑦ 지도홈 오른쪽 위 지도 버튼. 날짜와 시간을 바꾸면 핀 색이 바뀌고, 핀을 누르면 아래 카드, 카드 버튼을 누르면 ⑤
