5. **Open facts** —
   - Shapefile CRS is EPSG:4326 (`GCS_WGS_1984`). `gu` uses dong.geojson attribute `sggnm`. `lat`/`lon` is the centroid in EPSG:5179 transformed back to EPSG:4326 (at most 0.61 m from the degree-space centroid). No centroid falls outside every dong. Six centroids fall outside their own polygon (`POI080`, `POI087`, `POI105`, `POI110`, `POI121`, `POI126`) and still sit in the same 시군구 as most of the polygon. `POI070` 쌍문역 is an invalid polygon and was stored as read.
   - `fill_gap_by_place.csv` has 110 rows, not 111. `POI100` 서울대공원 is in the obs extracts but not that file. Those 11 places (POI100 plus the 10 with `serve_state=off`) keep the shapefile `CATEGORY`. On the 110-row overlap the two category columns agree. `foreign_heavy` is 11 with the six substrings unchanged.
   - `DATA_GO_KR_KEY` is not in `.env`. `name_en` is null on all 121 rows. Names were not invented. If that variable is set later, `load_places` exits with an error instead of guessing.
   - `open_hours` is set only for A2 heritage: `POI008` 경복궁 (closed Tuesday, 09:00–18:00, https://royal.khs.go.kr/ROYAL/contents/R702000000.do, checked 2026-10-01), `POI011` 서울 암사동 유적 (closed Monday, 09:30–18:00; not published by 궁능유적본부 — https://www.gangdong.go.kr/web/culture/contents/gdc020_010_020), `POI012` 창덕궁·종묘 (a weekday is open when at least one site admits visitors; Monday is 종묘's timed-entry span 09:20–16:20). A1 heritage `POI009` and `POI010` have no `open_hours`. The weekly table does not encode seasonal hours or the "closed day moves when it is a holiday" rule.
   - KASI names that were not in the original English list, added to `holiday_names_en.yaml`: `1월1일`, `국회의원선거`, `노동절`, `전국동시지방선거`, `제헌절`. Parenthetical names (`대체공휴일(설날)`, `임시공휴일(제21대 대통령 선거)`, …) resolve by the longest listed prefix. `2025-05-05` is both 부처님오신날 and 어린이날; the primary key is the date, so the row is `부처님오신날 · 어린이날` / `Buddha's Birthday · Children's Day`, kind `holiday`. `임시공휴일` does not contain 대체, so its kind is `holiday`.
